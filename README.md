Solar Bay is an open-world crime game: explore a sun-soaked fictional city on foot and by car, steal cars, outrun the police, and run story missions. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
